About quinn-wasm

This interface uses quinn-wasm compiled to WebAssembly to provide native QUIC protocol support in the browser. Combined with the Direct Sockets API available in Isolated Web Apps, this enables true UDP-based QUIC connections without WebSocket or WebTransport proxying.

// Connection example import init, { connect_quic_direct_sockets } from './quinn_wasm_direct_sockets.js'; await init(); const response = await connect_quic_direct_sockets('127.0.0.1:4433', 'Hello'); console.log('Server response:', response);
